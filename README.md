# Quiz Master 🏆

A timed multiple-choice quiz application built with Python and Tkinter. Test your knowledge, answer questions against the clock, and track your performance through a persistent leaderboard.

## ✨ Features

* **Multiple Categories:** General Knowledge, Science, Programming, and Mixed Categories.
* **Customizable Quiz:** Choose the number of questions and the time limit for each question.
* **Countdown Timer:** Each question has a timer, and unanswered questions count as incorrect.
* **Progress Tracking:** Follow your progress throughout the quiz.
* **Score Calculation:** View your final score and percentage.
* **Performance Chart:** Visualize correct answers by category.
* **Persistent Leaderboard:** Save scores and display the top five results.
* **Replay Option:** Start another quiz whenever you want.
* **Modern GUI:** A dark-themed interface built with Tkinter.

## 🛠️ Technologies Used

* Python 3
* Tkinter and ttk
* CSV for leaderboard storage
* Random for question selection
* Datetime for recording quiz dates

## 🚀 Getting Started

### Prerequisites

* Python 3 installed on your computer.
* Tkinter available with your Python installation.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/esr470/Quiz-Master.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Quiz-Master
   ```

3. Run the application:

   ```bash
   python quiz_app.py
   ```

## 🎮 How to Use

1. Enter your name.
2. Select a quiz category.
3. Choose the number of questions.
4. Set the time limit for each question.
5. Click **Start Quiz**.
6. Select an answer before the countdown ends.
7. Review your final score and category performance.
